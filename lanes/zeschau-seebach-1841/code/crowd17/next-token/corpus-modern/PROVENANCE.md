# Provenance — modern French corpus for gov-excl-inf-modern

Diachronic control corpus: early-20th-century French fiction (the target's bar
needs modern French as a control on the 1841-register fence; "modern" here =
1902–1913, post-1841 by 61–72 years, dialogue-heavy literary French).

- PG 13765: Gaston Leroux, "Le mystère de la chambre jaune" (1907)
- PG 62100: Marcel Proust, "Un amour de Swann" (1913)
- PG 13525: Louis Hémon, "Maria Chapdelaine" (1913)
- PG 73058: André Gide, "L'immoraliste" (1902)

All four are in French (ebook-page inLanguage=fr, verified 2026-10-09 before
download). Retrieved 2026-10-09 via curl from
`https://www.gutenberg.org/cache/epub/<id>/pg<id>.txt` (Project Gutenberg
public-domain ebooks; UTF-8 text). First attempted source (fr-Wikipedia
20220301 parquet shards) was abandoned: shard downloads timed out through the
egress proxy and the background fetch hit a runtime confirmation gate.

Register note: early-20th-c literary fiction (dialogue-rich) is not
present-day French, and it is not 1841 diplomatic print either; it tests
whether the governed-exclamatory-infinitive zero is period-bound to 1841
or persists into the 20th century. This limitation is stated in the report.
