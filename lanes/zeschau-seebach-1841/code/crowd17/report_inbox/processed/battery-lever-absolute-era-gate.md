## Method

No corpus pipeline was available to this worker, so the gate was run in the
lexicographic-authority form: every normative/descriptive authority spanning
the era was checked for (i) the grammatical class assigned to "lever",
(ii) any "absolument" (absolute, objectless) use of bare "lever", and
(iii) where the "rise/get up" senses are filed. Authorities checked:
Académie française 1e (1694), 2e (1718), 3e (1740), 4e (1762), 8e (1935)
editions; Littré (1872–1877, the 19th-century descriptive dictionary closest
to the era); and a modern distributional analysis of LEVER (Linx 66–67,
2012) as a structural cross-check. The Académie 6e (1835) page was not
directly fetched; the 1e–4e and 8e editions bracket it and agree unanimously.
All dictionary sources used are public domain.

## Evidence (source-by-source, with counts)

### S1. Littré, "lever" (littre.org/definition/lever; public domain)

- Headword class: **"lever ... v. a."** (verbe actif = transitive). 21
  numbered transitive senses, every one with an object.
- "Absolument" (absolute, objectless) marks under the BARE headword — 3
  occurrences, none a "rise/get up" use:
  - Sense 2: "Absolument. Lever les yeux, regarder en face" — object
    (les yeux) understood by ellipsis, not a true objectless verb.
  - Sense 11: "Absolument. Il était près de huit heures quand le conseil
    leva (Saint-Simon). ... Cet emploi a vieilli." — the single absolute
    bare use on record (assembly rising); Littré marks it OBSOLETE.
  - Sense 12 (trictrac/cards): "Absolument. J'aurai levé avant vous." —
    game term, object understood.
- Intransitive "lever" (senses 22–23, "V. n."): ONLY germination
  ("Les blés commencent à lever") and fermentation
  ("La pâte commence à lever").
- ALL "rise / get up / stand up" senses (24–28) are filed under
  **"Se lever, v. réfl."** (pronominal), including
  "Absolument. Se lever, sortir du lit" (Sévigné, Voltaire citations).
- Historique: absolute "lever" = "rise" IS attested in OLD French —
  "Li empereres est par matin levet" (Ch. de Roland, XIe s.);
  "à peine jamais en levera" (Berte, XIIIe s.). Dead by the classical
  period; diachronically irrelevant to 1841 but recorded for the red team.

**Littré count: absolute bare-'lever' = "rise/get up" in classical/modern
French: 0. Pronominal 'se lever' = "rise/get up": the entire 24–28 sense
block (dozens of citations).**

### S2. Académie française, 1e (1694), 2e (1718), 3e (1740), 4e (1762), 8e (1935)

- All five editions class "lever" as v. tr. / v. a. with objects throughout
  (lever la main, lever les yeux, lever la séance, etc.).
- 1e (1694), the edition that still preserves the oldest usage layer:
  "On dit absolument, Se lever, pour dire, Cesser d'estre assis & se tenir
  debout. ... On dit encore absolument, Se lever, pour dire, Sortir du lit."
  — the "absolument" rubric attaches to the PRONOMINAL, never to bare
  "lever".
- 8e (1935): "LEVER. v. tr. ... SE LEVER signifie Se dresser, se mettre
  debout sur ses pieds." Same filing.

**Académie count across 5 editions (1694–1935): bare absolute 'lever' =
"rise/get up": 0. 'Se lever' = "rise/get up": attested in every edition.**
