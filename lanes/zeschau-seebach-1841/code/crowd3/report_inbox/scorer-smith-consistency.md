## scorer-smith: global-consistency scorer — NULL with diagnosis (WO3)

- Context: WO3 ordered a redesign of the scorer around a GLOBAL-CONSISTENCY signal to fix round 2's N12 failure (placement-ranking ties; control top-1 0.021 < chance 0.076, MRR 0.133 < 0.30). I built `code/crowd3/scorer3.py`: for each candidate (group g, cell v), decode ALL occurrences of g under the anchor table + {g:v}, keep only the bigrams touching a g-position, score fit_i(v) = s_i(v) − mean(tier-matched background in the same window), and rank by (support, mean_margin) — support = fraction of occurrences where v beats the background. Reused round 2's rule syllabifier + two-tier cell model unchanged.
- Decision: **BROKEN-ON-CONTROL — report NULL, no real drag.** Three variants were built and control-validated; all failed the pre-registered bar (n_test ≥ 10, top-1 ≥ 3× chance, MRR ≥ 0.30). Nothing from this scorer touched R5005.
- Why: the control numbers, not a hunch. v1 (WO3 design as specified): top-1 0.045 = 4.0× chance, MRR 0.217 — FAIL. v2 (strong frequency background + W=3, fixing v1's support saturation): top-1 0.091 = 8.1× chance but MRR 0.165 — FAIL, worse. v3 (SYL candidates scored only on SYL–SYL bigrams, fixing v2's tier-crossing loss): top-1 0.071, MRR 0.217, 26/40 groups starved of data — FAIL. Each repair addressed a diagnosed flaw; each re-validation failed. The gate held.
- Enlightenment: the surprise was that the consistency signal is REAL but USELESS for identification — v1 showed median support(true) = 1.00 (the true cell beats a random background at every occurrence), yet many wrong cells also hit 1.00. French bigram contexts underdetermine a cell: single letters can't be told apart from other common letters (s/t/d/l attractors win), and the tier-crossing approximation lets edge-matching impostors ('s' for true 'les') outscore the truth. A weak null saturates, a strong null crushes the truth too — no per-occurrence aggregation fixes an uninformative likelihood. The aha: single-letter cells are emitted in split pairs (d|e) and syllables need syllable neighbors — identification needs JOINT assignment of multiple groups, which a per-group scorer can never do.
- For the report: belongs in the methods section under "scorer-smith round 3 (WO3)". The 3 numbers: best top-1 0.091 (8.1× chance 0.011) with MRR 0.165; best MRR 0.217 vs bar 0.30; verdict BROKEN-ON-CONTROL, real drag not run. Full evidence: `code/crowd3/scorer_smith_results.{json,md}`.
