## scorer-smith: syllable-level cell scorer (work order 4)
- Context: Work order 4 — build the syllable-level scorer the drag racer scoped (N6), with explicit calibration for the cipher's single-letter cells (m/i/e) and hyper-frequent "er" (rank 3), then re-run the function-word drag. Hard gate: a synthetic control FIRST (the N5 annealer failed exactly this test — its scorer's global optimum sat 2.5 nats/pair above real French). Built: a documented rule-based French syllabifier (no pyphen), a two-tier hybrid cell scorer (syllable tier from the era corpus + letter tier with stream-calibrated unigrams for m/i/e), and a synthetic encipherer reproducing the pencil's "la pre m i er e" granularity. Control: tail-1200w of Tocqueville t2 through a known random 96-cell syllabary with all 9 anchors pinned; drag run with the identical code; planted word placements must rank above chance (pre-registered bar: top-1 >= 3x chance AND MRR >= 0.30).
- Decision: **BROKEN-ON-CONTROL** — the real drag was NOT run (work order 4d). Do not use this scorer on the cipher. Design decisions I'd defend again: (1) rule-based segmenter over pyphen — pyphen's hyphenation units emit "er" at 52/313k while the cipher uses it as a rank-3 cell, so the inventory mismatch, not the math, was the racer's calibration bug; (2) letter-cell unigrams calibrated from the target stream, not the corpus — letter-cell emission is an encipherer choice the corpus cannot predict; (3) stopping at the gate — a broken scorer on the real cipher produces confident-looking garbage (N5's lesson).
- Why: the control isolates the scorer — the only unknown is the random mapping. It failed decisively: top-1 accuracy 0.021 vs chance 0.076 (0.3x), MRR 0.133 vs the 0.30 bar, 47 test words. The failure is NOT the language model: true French 50-cell runs score -3.12 vs -4.32 shuffled — the model knows French. The failure is placement ranking specifically: within one candidate every placement shares identical cells, so the internal score cancels and only 1-2 edge bigrams to adjacent anchors differ; at low anchor density the known run rarely extends past the candidate span, so many placements tie at the best local pattern (e.g. "de"/"le" true positions tied for best with 15+ decoys). The scorer can put truth in the tied-best set but cannot single it out. None of 12 multi-anchor test words (incl. "comme"=[com,m,e]) recovered at rank 1.
- Enlightenment: the missing signal is **global consistency of implied assignments** — the window scorer never checks whether group X='d' reads as 'd' everywhere X occurs in the stream. Every placement implies 1-2 new group->cell assignments; summing evidence over ALL occurrences of the implicated groups is the redesign that could actually discriminate. Second surprise: corpus P(standalone "er" unit)=0.0020 vs cipher 0.0255 (13x gap), but corpus P(unit ENDS in letters "er")=0.0211 ≈ cipher 0.0255 — the encipherer likely stripped final "-er" systematically (parl|er). That is a concrete, testable granularity claim for whoever builds the next scorer.
- For the report: Null results — new entry N10 (scorer-smith BROKEN-ON-CONTROL). The 3 numbers: top-1 0.021 vs chance 0.076; MRR 0.133 vs 0.30 bar; model check -3.12 (true) vs -3.92 (shuffled) proving the model is fine and the ranking is broken. All trace to `code/crowd2/scorer_smith_results.json` (method: `code/crowd2/scorer_smith.py`).
- Caveats: control plaintext is in-sample (training corpus; only the mapping unknown) — noted, not a leak. Control anchor coverage 0.288 vs the real cipher's ~0.14, so the control is EASIER on sparsity — the failure is conservative. Elision rate 0.32 (words with out-of-inventory cells dropped) is a harder-than-real artifact, but the tie-structure analysis shows the failure mechanism is independent of it. 87=ce and 64=qui are provisional lane-inferred anchors, pinned as true in the control. The "-er stripping" claim is an inference from corpus rates, not a verified encipherer rule.
