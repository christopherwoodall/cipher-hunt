## tester: key-table test harness built and validated
- Context: the key-hunt side fleet needs a way to score candidate historical key tables against R5005 byte-for-byte. I built `code/side-keyhunt/test_table.py` (with `canonical.py` + `build_syll_model.py` + `syll_bigram.json`).
- Decision: canonical parse is embedded from the lane-canonical rule (`upstream-ct_R5005.txt` + `upstream-offsets.json`), self-asserting on load — 3,764 digits, 1,846 pairs, 96 distinct groups, and the `11-70-82-34-29-40` run at pair index 1033 exactly once. Any table is checked against the 7 ground-truth anchors (11=la, 70=pre, 82=m, 34=i, 29=er, 40=e, 46=que) plus an exact "la première" read at pair 1033; 87=ce / 64=qui / 96=par are reported secondary and never gate the verdict. French-likeness = lane letter-quadgram score (primary) + a Tocqueville-era syllable-bigram model (secondary, rough syllabifier, see `build_syll_model.py`).
- Why: a near-miss must not read as a hit — verdicts are HIT (all 7 anchors + exact "la première" + all 96 groups mapped + quadgram ≥ −5.5/char) / NEAR-MISS (no contradiction, but partial or non-French) / MISS (contradiction or non-French score). The coverage gate exists because a table that only re-states the 7 known anchors proves nothing.
- Enlightenment: two things I caught while validating. (1) `crib_attack.py::qscore` pops `floor`/`meta` and then scores against the dict that still nests the real table under `'logp'` — so it always returns floor (−7.71); my harness scores against `logp` directly. Worth knowing if anyone reuses that function. (2) The anchors-only dummy table expands to fragments that score −4.7/char on quadgrams — French-*sounding* without being a table. That's exactly why the all-96-groups coverage gate is in the HIT bar.
- For the report: "Methods / tooling" — harness validated on three dummy tables: wrong-anchors → MISS ("anchor contradiction"); 7-anchors-only → NEAR-MISS ("partial table (7/96 groups)"); full 96-group table with correct anchors but random rest → NEAR-MISS ("expansion score −5.63/char below HIT bar −5.5"). Baselines: Tocqueville quadgram −4.25/char vs gibberish −7.7; syll-bigram French −4.21/syll vs scrambled −7.04. Dummies live in `code/side-keyhunt/dummies/` for reruns.
- Caveats: I could not positive-control a true HIT — no real full key table exists yet. The HIT verdict is reachable-by-construction only (full table + correct anchors + French expansion); first real table that clears it still deserves a human byte-read of the expansion. Syll-bigram score is approximate (rough syllabifier) — quadgram is the primary gate.
